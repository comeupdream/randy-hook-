# Vendored fonts

Variable webfonts served with `next/font/local` so builds are deterministic
and never depend on Google Fonts at build time.

| File | Family | Role |
| --- | --- | --- |
| `fraunces-var.woff2` / `fraunces-italic-var.woff2` | [Fraunces](https://fonts.google.com/specimen/Fraunces) | Display serif (headings, hero) |
| `source-sans-3-var.woff2` / `source-sans-3-italic-var.woff2` | [Source Sans 3](https://fonts.google.com/specimen/Source+Sans+3) | Body & UI sans |

Both families are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/)
and were downloaded from Google Fonts (latin subset, variable weight/optical axes).
